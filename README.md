# Visual Programming Coursework (VP)

A repository containing solutions to programming exercises and assignments for the Visual Programming (VP) course, built with **Java** and the NetBeans IDE.

---

## Package Structure

The source code follows the standard package structure:
`src/edu/zuj/vp/`

---

## Assignments Index

| Folder / Assignment | Task | Description |
| :--- | :--- | :--- |
| **`homework1`** | Basic Exercises | Introduction to basic syntax, arithmetic, and control flow. |
| **`homework2`** | `OvalStars` | Prints star patterns in an oval / diamond layout. |
| | `PyramidStars` | Formats and prints stars into an isosceles pyramid. |
| | `ReverseTriangleStar` | Right-aligned right-angled triangle star pattern. |
| | `RevertTriangleStar` | Inverted right-angled triangle starting wide and tapering down. |
| | `SquareStars` | Prints a square grid of stars based on user input. |
| | `TriangleStars` | Standard left-aligned right-angled triangle pattern. |
| **`homework3`** | `ArrayRead` | Reads an array of integers and calculates Sum, Average, Max, and Min. |
| | `ArrayReadMethod` | Array operations organized using modular Java methods. |
| | `ArrayReadRandom` | Populates arrays with random numbers (`Random`) and computes summary statistics. |
---

## Requirements & Setup

- **JDK**: Version 8 or higher.
- **IDE**: Apache NetBeans (or any IDE compatible with standard Ant projects).
To run any task, open the project in your IDE and run the `main` method of the respective class directly.
